# Text+Markdownエディタ（Windows 版）

Mermaid・Graphviz の図と数式に対応した Markdown エディタ「Text+Markdownエディタ」の、
Windows 版の配布用リポジトリです。インストーラーは [Releases](https://github.com/albos-inc/markdowneditor-releases/releases/latest) から入手できます。
このリポジトリにソースコードは置いていません。

紹介ページ: https://albos.jp/apps/markdowneditor/

## ダウンロードとインストール

1. [最新のリリース](https://github.com/albos-inc/markdowneditor-releases/releases/latest) の
   「Assets」から `TextMarkdownEditor-<バージョン>-setup.exe` をダウンロードします。
2. ダウンロードしたファイルを実行し、画面の案内に従って進めます。管理者の権限は要りません。
3. スタートメニューの「Text+Markdownエディタ」から起動します。

「Windows によって PC が保護されました」と表示された場合: このインストーラーにはデジタル署名を
付けていないため、Windows の SmartScreen がこの画面を出すことがあります。「詳細情報」を押してから
「実行」を押すと、インストールを続けられます。

## 動作環境

- Windows 10 / Windows 11（64 ビット版）
- [Microsoft Edge WebView2 ランタイム](https://developer.microsoft.com/microsoft-edge/webview2/)
  （プレビューの表示に使います。Windows 11 と、更新済みの Windows 10 には入っています）

# Text+Markdown Editor (Windows)

This repository distributes the Windows version of Text+Markdown Editor, a Markdown editor with
Mermaid and Graphviz diagrams and math. Download the installer from
[Releases](https://github.com/albos-inc/markdowneditor-releases/releases/latest).
The source code is not in this repository.

Website: https://albos.jp/apps/markdowneditor/

## Download and install

1. From the "Assets" of the [latest release](https://github.com/albos-inc/markdowneditor-releases/releases/latest),
   download `TextMarkdownEditor-<version>-setup.exe`.
2. Run it and follow the instructions. Administrator rights are not required.
3. Start "Text+Markdownエディタ" from the Start menu.

If Windows shows "Windows protected your PC": the installer is not digitally signed, so Windows SmartScreen may
show this screen. Click "More info", then "Run anyway" to continue.

## Requirements

- Windows 10 / Windows 11 (64-bit)
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
  (used for the preview; included in Windows 11 and up-to-date Windows 10)
